# AWS Partner: DevOps Essentials

Source language: English. AWS Skill Builder lists this as a one-hour digital course, selected language English, domain DevOps, level Fundamental, and Exclusive Access. The listing shows a last update of May 18, 2026. Successful completion is described as earning the AWS Partner: DevOps Essentials learning badge.

## Description

AWS Technical Field Communities developed this foundational course to complement AWS's standard training curriculum. It is intended for AWS Partner business development, sales, pre-sales technical, and technical delivery roles. In about 60 minutes, learners build knowledge for customer conversations about Cloud Operations on AWS, identify partner opportunities, and use AWS programs and resources to deliver solutions. The listing directs learners who need accessibility accommodations to AWS Training and Certification Customer Support.

## Objectives

1. Explain DevOps principles and practices, including continuous integration, continuous delivery, and infrastructure as code.
2. Recognize industry trends, common customer challenges, and DevOps opportunities to position AWS solutions.
3. Explore AWS CodePipeline and AWS CloudFormation, and recommend solutions for different customer scenarios.
4. Identify AWS services and solutions for common DevOps use cases and build confidence in solution design and customer conversations.
5. Discover AWS Partner Network resources, including technical documentation, training materials, and go-to-market support for building and growing a DevOps practice.
