## 2. Welcome to the Course

Morgan Willis, AWS Principal Cloud Technologist, welcomes learners to AWS Partner Accreditation (Technical). The five-hour parent learning experience is a high-level technical introduction to AWS cloud computing, global infrastructure, services, solutions, and security. Its practical goal is to help a partner discuss technical choices and recommend AWS products in response to customer requirements.

The welcome video explains the learning route. The first activity is AWS Technical Essentials, averaging about four hours; it builds console familiarity and covers compute, databases, storage, networking, monitoring, and security. Learners then return to the parent course for three shorter topics: AWS CAF, common migration strategies, and the AWS Well-Architected Framework. CAF connects AWS experience and practices to customer transformation and business outcomes. The migration topic helps match an approach to a customer's workload and situation. Well-Architected introduces design and operating practices for secure, reliable, efficient, cost-effective, and sustainable workloads.

The digital course is self-paced and saves progress between sessions. Additional resources at the end support deeper study and customer conversations. The final accreditation assessment covers AWS Technical Essentials, AWS CAF, migration strategies, and Well-Architected. The in-lesson knowledge checks are practice; only the final assessment counts toward the badge. The lesson says a successful assessment earns the AWS Partner Accreditation (Technical) badge, issued through Credly in 2–3 business days.
