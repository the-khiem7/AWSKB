# Course Introduction

## 1. Welcome to the Course

Morgan Willis, Principal Cloud Technologist at AWS, introduces the course as a technical foundation for people with general IT knowledge who are new to AWS Cloud.

The course sequence covers:

- Cloud fundamentals, cloud benefits, AWS global infrastructure, and IAM.
- Compute: EC2, AWS container services including ECS, and serverless options including Lambda.
- Networking: Amazon VPC and related technologies for creating, securing, and connecting private AWS networks.
- Storage: S3, EBS, and other storage services.
- Databases, with emphasis on RDS and DynamoDB.
- Monitoring and scaling using CloudWatch, EC2 Auto Scaling, and Elastic Load Balancing.

The course builds a cloud-based employee-directory application incrementally; it stores images and information about fictional employees. No coding is required, although source code is available for optional exploration. The instructor recommends completing the written readings and notes as well as videos because they reinforce concepts and provide background beyond the video material.

## 2. Meet the Instructors

Morgan Willis, a Principal Cloud Technologist, and Seph, a Cloud Technologist, introduce themselves as the course instructors. Both describe backgrounds across developing, building, training, and sharing AWS knowledge. The course uses their sidekick characters, Meowzy and Fluffy, for occasional tips and examples.
