## Course Overview

Kubernetes Event-Driven Autoscaling (KEDA) extends Kubernetes clusters with event-driven scaling. It is useful when workloads should react to events such as messages arriving in a queue, instead of relying only on conventional metrics such as CPU or memory. KEDA augments Kubernetes' native scaling with event-driven logic, helping cloud-native applications respond to changing event workloads. The course positions itself as a foundation for developers, DevOps professionals, and cloud learners specializing in Kubernetes.

### Learning objectives

By the end of the course, learners should be able to:

1. Describe Kubernetes autoscaling and its limitations.
2. Explain when event-driven autoscaling is suitable and what KEDA contributes.
3. Outline KEDA's architecture and core components.
4. Explain how KEDA turns events into scaling actions in a Kubernetes cluster.
5. Identify how scalers connect event sources to scaling behavior.
6. Deploy KEDA for event-driven workloads.

### Additional details

Additional course information is grouped into eight expandable panels:

- **Audience:** developers, DevOps professionals, and anyone interested in Kubernetes and event-driven autoscaling.
- **What the course prepares learners to do:** design and deploy applications that scale dynamically with actual demand to support resource utilization and performance.
- **Prerequisites:** familiarity with basic Kubernetes workloads such as Deployments and Horizontal Pod Autoscalers (HPA); command-line experience is recommended.
- **Lab environment:** one Ubuntu 24.04 virtual machine, which can be created with a cloud provider of the learner's choice. The course says it includes a script to help create Kubernetes clusters.
- **Duration and access:** approximately one hour of course work; access lasts 12 months from registration or until the subscription expires, whichever comes first.
- **Assessment:** a final exam is required, with a score of at least 70% to complete the course successfully.
