# Course Completion

## Course feedback

The section begins with an embedded Linux Foundation Education survey. Its introduction explains that learner feedback is used to improve training courses and the learning experience. The initial screen displays the survey title, an introductory note, a privacy notice link and a **Next** control.

The course-completed screen also presents an optional five-star rating and comment field. These are learner feedback controls rather than instructional material.

## Final exam instructions

The course requires a ten-question final exam. The passing threshold is 70%. Each question permits one submission within an exam attempt; the course allows another exam attempt if needed. Learners select the best answer or answers, advance with **Next Question**, then choose **See Results** after the last question. The results screen offers a review of responses, a retake option and continuation to the next section. The instructions warn that page-arrow navigation can leave the exam; the side menu can be used to return.

The assessment covers KEDA's event-driven scaling compared with HPA, supported event sources, scaling practices, resource and cost benefits, common autoscaling problems, `ScaledObject` and operator roles, and scaling from queue depth.

## Completion certificate visual

The certificate design uses a centered Linux Foundation logo on a white upper field and a bright-blue lower field separated by a white downward-pointing chevron. A recognition block and course title appear on the blue field. The lower area places a signature block at left, a date in the center and a certificate identifier at right. The certificate contains learner-specific information, which is kept out of these public course notes.
