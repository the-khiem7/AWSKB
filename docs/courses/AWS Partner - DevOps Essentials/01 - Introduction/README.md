# Introduction

## Course Introduction — lesson 1 of 14

The opening describes AWS Partner: DevOps Essentials as a foundational course for AWS Partner business development, sales, pre-sales technical, and technical delivery roles. It estimates approximately 60 minutes and aims to build knowledge for effective customer conversations about Cloud Operations on AWS, recognizing partner opportunities, and using AWS programs and resources to deliver solutions.

### Course objectives

1. **Define and explain core concepts:** explain key terminology, frameworks, or value propositions and describe the fundamental approach or methodology. The spoken introduction names continuous integration, continuous delivery, and infrastructure as code as DevOps practices that support customer transformation conversations.
2. **Identify market context:** recognize relevant industries, customer segments, market opportunities, customer challenges, and business drivers so AWS solutions can be positioned against specific pain points.
3. **Describe AWS capabilities:** explain services, features, and architectural approaches and connect their technical capabilities to customer requirements and use cases. AWS CodePipeline and AWS CloudFormation are named as services that enable DevOps practices.
4. **Apply knowledge to customer scenarios:** address common questions, objections, and concerns; connect business needs to AWS solutions; and use customer examples to build confidence in solution design and customer conversations.
5. **Leverage partner resources:** find AWS Partner Network (APN) programs, technical documentation, training, go-to-market support, and other resources to build and grow a DevOps practice and plan role-specific next steps.

The lesson says real-world examples and practical exercises reinforce these outcomes for business development, sales, and technical roles. Its opening text also directs learners to **START COURSE**, select a lesson title to jump to a topic, or open **How to Use This Course** for navigation guidance.
