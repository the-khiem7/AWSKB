## Assessment questions

All 20 questions were answered correctly on the first attempt. The selection was marked correct after every submission, and the results page reported a 100% score and Passed against the 80% threshold.

1. **What does AWS CodeDeploy do?** A. Compiles and builds source code. B. Manages source code repositories. C. Creates infrastructure templates. D. Automates application deployments to compute services such as EC2 and Lambda. **Correct answer: D.**
2. **In the context of DevOps on AWS, what does “Continuous Delivery” (CD) refer to?** A. Managing physical hardware. B. Writing new code every day. C. Automatically preparing code changes for production after automated tests. D. Monitoring servers. **Correct answer: C.**
3. **Which AWS service is a fully managed source control service that hosts Git-based repositories?** A. AWS CodeBuild. B. AWS CodeCommit. C. AWS CodeDeploy. D. AWS CodeStar. **Correct answer: B.**
4. **Which AWS service is used for defining infrastructure as code using YAML or JSON templates?** A. AWS CodeBuild. B. AWS CloudFormation. C. AWS CodePipeline. D. AWS CodeDeploy. **Correct answer: B.**
5. **What is the purpose of AWS CodePipeline?** A. Provision cloud infrastructure. B. Automate the release process through build, test, and deploy stages. C. Monitor application performance. D. Store source code repositories. **Correct answer: B.**
6. **What is a key benefit of DevOps for organizations?** A. Faster feature delivery, increased deployment frequency, and more reliable releases. B. Eliminating testing. C. Less monitoring. D. Slower release cycles. **Correct answer: A.**
7. **Which visual representation is commonly used to illustrate the DevOps lifecycle?** A. A pyramid. B. A linear pipeline. C. An infinity loop. D. A waterfall. **Correct answer: C.**
8. **What is Infrastructure as Code (IaC)?** A. Documenting infrastructure after manual deployment. B. An AWS-only programming language. C. Managing and provisioning infrastructure with machine-readable configuration rather than manual processes. D. Application code running on physical servers. **Correct answer: C.**
9. **What is one key customer conversation insight for AWS Partners when discussing DevOps?** A. DevOps is only relevant to startups. B. DevOps only applies to on-premises environments. C. Organizations adopting DevOps practices can achieve both speed and reliability — they don't have to choose one over the other. D. DevOps eliminates the need for security. **Correct answer: C.**
10. **What does Continuous Integration (CI) primarily involve?** A. Manually reviewing every code change before it's committed. B. Developers frequently merging code changes into a shared repository with automated builds and tests. C. Running infrastructure provisioning scripts on a schedule. D. Deploying code directly to production without testing. **Correct answer: B.**
11. **What should partners do to track DevOps-related customer opportunities and maintain alignment with AWS?** A. Email their AWS Partner Manager directly. B. Use the AWS Partner Funding Portal. C. Submit a support ticket. D. Track opportunities in the ACE (AWS Customer Engagements) tool. **Correct answer: D.**
12. **According to the course, how much services revenue can AWS Partners potentially generate for every $1 of AWS technology sold through DevOps engagements?** A. $5. B. Over $7. C. Over $10. D. $2. **Correct answer: B.** This is the course's reported opportunity figure; it is recorded here as course content, not independently verified market data.
13. **Which of the following best describes the “Plan” phase of the DevOps lifecycle?** A. Monitoring application performance. B. Running automated tests. C. Defining work, tracking progress, and collaborating on requirements. D. Deploying code to production. **Correct answer: C.**
14. **Which type of partner revenue opportunity does helping organizations assess their DevOps maturity and build transformation roadmaps represent?** A. Implementation Services. B. Resale Services. C. Advisory Services. D. Managed Services. **Correct answer: C.**
15. **Which AWS service provides a fully managed continuous integration service that compiles source code, runs tests, and produces software packages?** A. AWS CodeDeploy. B. AWS CloudFormation. C. AWS CodeCommit. D. AWS CodeBuild. **Correct answer: D.**
16. **Which of the following is a key market trend driving DevOps adoption?** A. Speed to market — companies rapidly moving from idea to production are disrupting markets. B. Organizations moving away from automation. C. Reduced need for software development. D. Decreased cloud adoption rates. **Correct answer: A.** The accessibility label for option A appended the unrelated text “Integrate the Provisioned Throughput with AWS Lambda functions” directly after the answer. It appeared to be stray accessibility content; the answer itself was clearly the speed-to-market trend and was marked correct.
17. **What percentage of strategic workloads are estimated to still be running on-premises, representing a modernization opportunity for AWS Partners?** A. 28%. B. 67%. C. 42%. D. 15%. **Correct answer: C.**
18. **Which of the following is NOT one of the “three pillars” of a DevOps practice?** A. Infrastructure as Code. B. Monitoring and Logging. C. Manual change approval boards. D. Continuous Integration / Continuous Delivery. **Correct answer: C.**
19. **What is the primary goal of DevOps?** A. To unify software development and IT operations to deliver value faster and more reliably. B. To eliminate the need for operations teams. C. To move all workloads to the cloud. D. To replace manual testing with automated testing only. **Correct answer: A.**
20. **What is a primary benefit of using Infrastructure as Code over manual infrastructure management?** A. It ensures consistency across environments and provides a complete audit trail of changes. B. It requires no technical knowledge. C. It eliminates the need for cloud services. D. It is only useful for small-scale deployments. **Correct answer: A.**
