## Objectives

- Describe AWS-service terminology and concepts, and navigate the AWS Management Console.
- Explain AWS security measures and IAM concepts.
- Differentiate EC2 and Lambda, plus container services including ECS and EKS.
- Describe RDS, DynamoDB, and S3.
- Explore AWS networking services and configure CloudWatch monitoring features.

## Intended audience and prerequisites

The course targets people who explain AWS technical benefits to customers, AWS beginners, SysOps administrators, solutions architects, and developers. It recommends IT experience and basic familiarity with data-center components, but requires no prior cloud or AWS experience.
